## Sample Retention and Disposal Schedule ##

This folder contains the sample RDS.xlsx workbook referenced in the main AI Classification Lab README.

The workbook combines classification classes from the National Archives of Australia's AFDA Express Version 2 and is provided as a learning resource for experimenting with AI-assisted records classification using Copilot in SharePoint.

It is intended for demonstration and educational purposes only, not as an authoritative retention and disposal schedule for an organisation.
